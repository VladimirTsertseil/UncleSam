# Калькулятор анестезии

Статическое приложение на русском языке для пересчёта введённых врачом доз у взрослых. Рассчитывает болюсы и инфузии для индукции и поддержания анестезии. Справочные дозы привязаны к показаниям и конкретным инструкциям. Рассчитанные объёмы и скорости нужно сверять с назначением, массой пациента и фактической концентрацией перед введением. Приложение не проходило клиническую валидацию.

## Публикация на GitHub Pages

1. Распакуйте ZIP. В корень ветки `main` добавьте **содержимое архива**, так чтобы `index.html` был на верхнем уровне рядом с остальными файлами.
2. В настройках репозитория откройте **Settings → Pages → Build and deployment**. В **Source** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку **/(root)**. Нажмите **Save**. Когда публикация завершится, откройте адрес в разделе **Pages**. Для проекта это обычно `https://ВЛАДЕЛЕЦ.github.io/РЕПОЗИТОРИЙ/`.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

Для локального запуска можно открыть `index.html`. Для надёжной проверки браузерного хранения запустите в папке проекта `python3 -m http.server 8000` и откройте `http://localhost:8000/`. Сборка, внешние библиотеки и ключи доступа не требуются.

## Работа с калькулятором

- **Расчёт.** Выберите сценарий и задайте массу. Между карточками препаратов переходите свайпом или стрелками. Дозу можно изменить кнопками «−» и «+» или ввести вручную. При смене единицы введите новое значение. Нажмите «Итог», чтобы увидеть расчёты и недостающие поля обоих этапов.
- **Болюс.** Поддерживаются мг, мкг, мг/кг и мкг/кг. Объём появляется после выбора или ввода фактической концентрации.
- **Инфузия.** Доза может быть в мг или мкг, суммарно либо на кг, в минуту или час. Приложение считает прямой и обратный пересчёт. Концентрацию можно ввести как мг/мл или мкг/мл либо рассчитать по количеству препарата и итоговому объёму раствора.
- **Расчётная масса.** В каждой строке на кг можно ввести отдельную массу. В сценарии при морбидном ожирении ввод расчётной массы обязателен для весовых строк. Это правило можно настроить в каждой строке.
- **Препараты.** Добавляйте, переименовывайте и удаляйте записи. Сохраняйте несколько концентраций, несколько доз, диапазоны в виде текста, примечания и ссылки. Для справочного диапазона введите выбранную дозу вручную. Числовую справочную запись можно подставить нажатием.
- **Сценарии.** Встроенные сценарии открываются с редактируемыми примерами доз. Откройте кнопку настроек рядом с полями сценария и массы, чтобы изменить состав или сохранить шаблон. «Обновить сценарий» записывает текущий список препаратов, дозы, концентрации и параметры поддержания. «Сохранить как сценарий» создаёт новый шаблон. Фактическая и расчётная масса пациента в шаблон не сохраняются. Кнопка «Новый пациент» сбрасывает массу и возвращает настройки выбранного шаблона.
- **Резервная копия.** Экспортируйте и импортируйте JSON в конце вкладки «Препараты». Импорт по подтверждению заменяет все текущие препараты и сценарии. При смене устройства либо адреса сайта переносите их через JSON.

## Стартовые дозы

Значения в сценариях предназначены для пересчёта после выбора клинической тактики. Источники доступны в справочных записях каждой карточки. Для фентанила российская инструкция «Эндофарм» указывает 100–200 мкг суммарно при вводной анестезии. Весовые значения в шаблонах — примеры для пересчёта, с пояснениями в справочнике. Сверьте дозу и фактическую концентрацию перед применением.

Обновление подставляет новые значения только в старые заводские сценарии в исходном виде. Собственные и отредактированные сценарии сохраняются.

## Примеры для проверки арифметики

| Ввод | Ожидаемый результат |
| --- | --- |
| 80 кг, 1,5 мг/кг, 10 мг/мл | 120 мг и 12 мл |
| 80 кг, 2 мкг/кг, 50 мкг/мл | 160 мкг и 3,2 мл |
| 80 кг, 6 мг/кг/ч, 10 мг/мл | 480 мг/ч и 48 мл/ч |
| 80 кг, 48 мл/ч, 10 мг/мл, результат в мкг/кг/мин | 100 мкг/кг/мин |

## Вкладка «Инфузии»

- **Текущий пациент.** Масса и сценарий общие для вкладок «Индукция» и «Инфузии». «Новый пациент» сбрасывает массу и текущие правки обеих вкладок, сохраняя выбранный шаблон. Значения текущего пациента держатся только до закрытия или перезагрузки страницы.
- Нажмите **«Добавить инфузию»** под карточкой поддержания и выберите препарат. Новая карточка появится в той же ленте. Для расчёта используйте дозу и концентрацию, для обратного пересчёта выберите направление в настройках карточки.
- **Справочные дозы** подписаны по показаниям с прямыми ссылками на клинические рекомендации, методические рекомендации или инструкции. Зарубежные источники обозначены отдельно. При открытии препарата вводится только единица, а дозу и разведение выбирает врач.
- «Итог» показывает расчёты всех карточек вкладки, включая добавленные инфузии. Во вкладке «Индукция» итог относится только к индукции.
- Свои дозы и концентрации редактируются в справочнике. Введённое разведение можно сохранить в настройках карточки. Экспорт включает сохранённые разведения, но не массу пациента или текущие поля инфузомата.
- Проверка по примеру со скриншота: 80 кг, 1 мг в итоговых 20 мл, 5 мл/ч дают приблизительно 0,0521 мкг/кг/мин. Обратный расчёт для 0,05 мкг/кг/мин даёт 4,8 мл/ч.

- В справочнике добавлены метопролол, калия хлорид, кальция хлорид и глюконат, натрия гидрокарбонат, липидная эмульсия 20%, эфедрин и ондансетрон. Для калия хлорида и натрия гидрокарбоната инфузомат поддерживает ммоль/ч и концентрацию в ммоль/мл. В карточке «Липидная эмульсия 20%» приведён алгоритм LAST по ASRA.
