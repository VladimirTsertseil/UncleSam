# Калькулятор анестезии

Статическое приложение на русском языке для пересчёта введённых врачом доз у взрослых. Рассчитывает болюсы и инфузии для индукции и поддержания анестезии. Справочные дозы привязаны к показаниям и конкретным инструкциям. Рассчитанные объёмы и скорости нужно сверять с назначением, массой пациента и фактической концентрацией перед введением. Приложение не проходило клиническую валидацию.

## Публикация на GitHub Pages

1. Распакуйте ZIP. В корень ветки `main` добавьте **содержимое архива**, так чтобы `index.html` был на верхнем уровне рядом с остальными файлами.
2. В настройках репозитория откройте **Settings → Pages → Build and deployment**. В **Source** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку **/(root)**. Нажмите **Save**. Когда публикация завершится, откройте адрес в разделе **Pages**. Для проекта это обычно `https://ВЛАДЕЛЕЦ.github.io/РЕПОЗИТОРИЙ/`.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

Для локального запуска можно открыть `index.html`. Для надёжной проверки браузерного хранения запустите в папке проекта `python3 -m http.server 8000` и откройте `http://localhost:8000/`. Сборка, внешние библиотеки и ключи доступа не требуются.

## Работа с калькулятором

- **Расчёт.** Выберите сценарий и задайте массу. Добавляйте и переставляйте строки на этапах индукции и поддержания. Для ингаляционного метода предусмотрено текстовое поле для параметров. В разделе «Сводка расчётов» видны заполненные строки обоих этапов.
- **Болюс.** Поддерживаются мг, мкг, мг/кг и мкг/кг. Объём появляется после выбора или ввода фактической концентрации.
- **Инфузия.** Доза может быть в мг или мкг, суммарно либо на кг, в минуту или час. Приложение считает прямой и обратный пересчёт. Концентрацию можно ввести как мг/мл или мкг/мл либо рассчитать по количеству препарата и итоговому объёму раствора.
- **Расчётная масса.** В каждой строке на кг можно ввести отдельную массу. В сценарии при морбидном ожирении ввод расчётной массы обязателен для весовых строк. Это правило можно настроить в каждой строке.
- **Препараты.** Добавляйте, переименовывайте и удаляйте записи. Сохраняйте несколько концентраций, несколько доз, диапазоны в виде текста, примечания и ссылки. Для справочного диапазона введите выбранную дозу вручную. Числовую справочную запись можно подставить нажатием.
- **Сценарии.** «Обновить сценарий» записывает текущий список препаратов, дозы, концентрации и параметры поддержания. «Сохранить как сценарий» создаёт новый шаблон. Фактическая и расчётная масса пациента в шаблон не сохраняются. Кнопка «Новый пациент» сбрасывает массу и возвращает настройки выбранного шаблона.
- **Резервная копия.** В настройках экспортируйте и импортируйте JSON. Импорт по подтверждению заменяет все текущие препараты и сценарии. При смене устройства либо адреса сайта переносите их через JSON.

## Примеры для проверки арифметики

| Ввод | Ожидаемый результат |
| --- | --- |
| 80 кг, 1,5 мг/кг, 10 мг/мл | 120 мг и 12 мл |
| 80 кг, 2 мкг/кг, 50 мкг/мл | 160 мкг и 3,2 мл |
| 80 кг, 6 мг/кг/ч, 10 мг/мл | 480 мг/ч и 48 мл/ч |
| 80 кг, 48 мл/ч, 10 мг/мл, результат в мкг/кг/мин | 100 мкг/кг/мин |
