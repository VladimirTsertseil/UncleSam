# UncleSam — система интерфейса v1

**Первый этап:** 16.11.2026. Образец для последующего переноса в «Инфузии» и «Калькуляторы» — вкладка «Индукция».

## Цель

Один визуальный язык для клинических расчётов: компактный профиль пациента, ясное представление дозы и объёма, наглядный выбранный вид массы, раскрываемые подробности и управление, пригодное для iPhone.

## Архитектура

- `style.css` — существующий интерфейс и пока не перенесённые разделы. Не добавлять сюда очередные частные поправки новых компонентов.
- `design-system.css` — единые переменные оформления и универсальные классы `.ui-workspace`, `.ui-card`, `.ui-icon-button`, `.ui-pill`, `.ui-eyebrow`, `.ui-result-panel`.
- `induction-ui.css` — оформление первичного экрана «Индукция», сгруппированных настроек сценария, блока пациента и карточек с дозой.
- `app.js` — разметка и состояние. Математика остаётся в `calc.js` и `body-mass.js`.

## Правила

1. **Число важнее оформления.** Доза — крупным текстом, объём при заданной концентрации — отдельной строкой с единицами. Не окрашивать правильный арифметический результат как медицински «безопасный».
2. **Выбранная масса — на поверхности.** Короткая метка `ФМТ / ИдМТ / СкМТ / ТМТ / Вручную · … кг` всегда видна около заголовка весозависимой карточки. Подробности за кнопкой-весами.
3. **Минимальный размер зоны нажатия — 44 × 44 px.** Особенно для стрелок, весов, сворачивания профиля, настройки сценария.
4. **Однотипные поля и отступы.** Использовать токены `--ui-s1…s6`, радиусы и цвета из `design-system.css`. Размер шрифта внутри `input/select` — не менее 16 px, чтобы Safari iOS не масштабировал страницу при фокусе.
5. **Предупреждение — отдельный блок.** Янтарный фон для информации, требующей проверки. Не использовать его для обычного результата. Данные и источники остаются доступными.
6. **Компактность не означает скрывать критическое.** Прячем описания, справочные дозировки и параметры приготовления, но оставляем на виду используемую массу, дозу и полученный объём.
7. **Сохранение существующих событий.** `data-field`, `data-stage`, `data-index`, `data-action`, `data-answer`, `data-math`, `data-mass-widget` не переименовываются без тестов.
8. **Новые разделы внедрять постепенно.** Следующая миграция — «Инфузии», затем клинические калькуляторы. Не менять весь код одной операцией.

## Визуальные токены v1

| Назначение | Токен |
|---|---|
| Основной текст | `--ui-ink` |
| Вспомогательный текст | `--ui-subtle` |
| Акцент и активное действие | `--ui-primary` |
| Фоновая поверхность | `--ui-surface` |
| Фон результата и компактных меток | `--ui-surface-alt` |
| Граница элемента | `--ui-border` |

| Карточка / управление | `--ui-radius-card`, `--ui-radius-control` |
| Минимальная интерактивная область | `--ui-target` |

## Что сделано в «Индукции»

- Размечен обособленный рабочий экран `.ui-workspace.ui-induction`.
- Сгруппированы сценарий и кнопка его настройки, без наложения второго элемента на первое поле.
- Уплотнён профиль пациента и сохранено его сворачивание.
- Обновлена структура карточки; метка массы теперь видна без открытия списка.
- Расчёт дозы и пересчёт в миллилитры разнесены визуально; общее текстовое значение для «Итога» сохранено.
- Дополнительные настройки, справочные дозы, источники и предупреждения сохранены.
- Сохранён прежний алгоритм выбора массы и расчёта — рефакторинг оформления не меняет клинические формулы.

## Что проверить на устройстве

- Safari iPhone с шириной 320 / 375 / 390 / 430 px; портретная и альбомная ориентация.
- Увеличенный системный шрифт и открытая клавиатура.
- Кнопка-весы: открытие, выбор массы, ручной ввод и повторное закрытие.
- Перемещение между препаратами стрелками и свайпами.
- Кнопка «−»/«+» в профиле; сохранение введённых данных.
- Настройки сценария: выпадение, скроллинг, закрытие и сохранение.
- Смена единиц мг/кг ↔ мкг/кг, концентраций, расчёт объёма и итог.
- Отключение сети и перезагрузка: сценарии и сохранённые данные.

## Ограничения выполненного этапа

Сделана проверка синтаксиса и программная проверка событий в имитации DOM; **не проводилось визуальное браузерное тестирование на iPhone**. Существующий `style.css` остаётся в проекте до последовательного переноса других разделов.
