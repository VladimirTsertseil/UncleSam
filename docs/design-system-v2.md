# UncleSam — система дизайна v2

**Дата:** 16.11.2026  
**Внедрено:** «Индукция», «Инфузии», «Калькуляторы».  
**Задача:** общий клинический минимализм без изменения медицинских формул.

## Архитектура

| Файл | Назначение |
|---|---|
| `style.css` | прежние разделы и базовая разметка, пока не переведённые на новые компоненты |
| `design-system.css` | токены и универсальные компоненты (`ui-workspace`, `ui-card`, `ui-pill`, `ui-eyebrow`, `ui-result-panel`) |
| `induction-ui.css` | профиль пациента, выбор сценария, интерфейс индукции |
| `infusion-ui.css` | видимые масса, доза и скорость насоса, разведение, кнопки режима инфузии |
| `calculators-ui.css` | клинические калькуляторы, формы, массы, результаты и ссылки на источники |
| `app.js` | состояние и представление индукции/инфузий, без изменения математического модуля |
| `calculators.js` | представление и управление калькуляторами, без изменения формул шкал |

## Основные правила

1. **Одинаковая визуальная иерархия:** заголовок → выбранная расчётная масса → ввод → главный результат → вспомогательный результат → источники/настройки.
2. **Инфузии:** при известной концентрации главным результатом служит **скорость инфузомата в мл/ч**, вторичным — **масса действующего вещества за единицу времени**. Если концентрация ещё не введена, отображается только доза действующего вещества за время.
3. **Обратный режим инфузии:** главное число — рассчитанная дозировка в единицах выбранной шкалы, вторично показывается введённая скорость насоса в мл/ч.
4. **Индукция:** главное число — общая доза в мг или мкг, вторичное — миллилитры при выбранной концентрации.
5. **Клинические калькуляторы:** число риска, индекс или расчётный показатель показывается крупно, без зелёной «галочки безопасности». Интерпретация, действия и источники сохраняются отдельно.
6. **Выбранная масса видна без раскрытия:** `ФМТ`, `ИдМТ`, `СкМТ`, `ТМТ` с числом кг там, где масса участвует в вычислении. Кнопка-весы сохраняет полный выбор и пояснения.
7. **Единое управление:** интерактивные области минимум 44×44 px, поля на iOS 16 px, показ ошибок отдельным предупреждением.
8. **Источники и клинические предупреждения не скрывать за результатом:** они остаются доступны в прежних разделах. Отображение результата не доказывает безопасность назначения.
9. **Не изменять формулы ради дизайна:** `calc.js`, `body-mass.js`, `risk-calculators.js` и `critical-calculators.js` без изменений на этом этапе.

## Проверки

- 36/36 тестов `tests/induction-regression.js` математического ядра.

## Границы

**Не выполнено:** ручное визуальное тестирование в Safari на реальном iPhone, автоматический браузерный тест responsive-раскладки, полный клинический аудит инфузий и всех калькуляторов. Перед клиническим применением необходима отдельная проверка клинических источников и ошибок ввода.
